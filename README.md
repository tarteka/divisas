# Divisas

Este proyecto fue generado con [Angular CLI](https://github.com/angular/angular-cli) versión 17.2.0.

## Acerca de

**Mercado de Divisas** es una aplicación web desarrollada con **Angular** que consume la **API pública de Frankfurter** para la consulta de tipos de cambio entre divisas.

Se trata de un proyecto académico realizado para el módulo **Desarrollo Web en Entorno Cliente** del **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web**, impartido en **BIRT.eus**.

## Tecnologías y recursos utilizados

- **Angular** – Framework principal del proyecto.
- **Frankfurter API** – API pública para la obtención de datos de divisas.
- **MockAPI.io** – Creación de la API REST utilizada para el libro de visitas.
- **Bootstrap** – Framework CSS para el diseño y maquetación de la interfaz.
- **Moment.js** – Librería JavaScript para la manipulación y formateo de fechas.
- **Chart.js** – Librería JavaScript para la generación de gráficos.
- **Flaticons.es** – Descarga del logotipo utilizado en la aplicación.
